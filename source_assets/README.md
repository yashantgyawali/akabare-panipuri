# Akabare Panipuri — Printable Asset Pack v0.6

This pack contains the playable card assets based on Prototype Rules v0.6.

## Folders
- `svg/` — individual printable card files, grouped by player colour
- `print_sheets/` — high-resolution PNG card fronts/backs
- `Akabare_Panipuri_Master_Print_v0_6.pdf` — A4 print master
- `Akabare_Panipuri_Rules_v0_6.pdf` — rules reference
- `ASSET_INVENTORY.txt` — component inventory

## Card count
6 player sets × 10 cards = 60 cards.

The six cards that make up each player's playable set are:
5 Panipuri, 1 Akabare, 1 Vinegar, 1 Dahi, 1 Khali Puri, 1 Chaat.

The master print PDF is arranged for physical cutting on A4.
